Aviation reference tool / 01

查机 · Aircraft Finder

按注册号查找飞机资料。

公开页面 · 网页工具
打开查机 查看源码

OVERVIEW

项目介绍

按注册号或关键词查找飞机资料，查看机型、航司、联盟和典型客舱布局，并按航司、机型或联盟继续浏览。

01

查询资料

输入注册号或关键词，查看对应飞机的机型、航司和典型客舱。

02

筛选浏览

按航司、机型、地区或联盟筛选，打开相关资料。

03

显示来源

页面保留来源与外部查询入口；典型客舱使用比例条和图例。

PROJECT NOTES

使用说明

资料来自公开数据快照；典型客舱不等同于每架飞机的实际配置，页面也不提供实时飞行位置。
